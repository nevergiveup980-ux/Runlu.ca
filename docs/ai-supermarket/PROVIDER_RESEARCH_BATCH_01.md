## Important distinctions
1. An independent factual review or official outbound link is not a claim of affiliation, endorsement, logo rights, referral commission or resale permission.
2. Integrating a vendor API into a genuine RUNLU-owned application can be governed differently from selling API keys, user seats, subscriptions, raw inference credits, or proxy access.
3. Consumer subscription credentials must never be treated as developer API authorization.
4. Official terms may change; dated screenshots or archived copies are evidence, not ongoing authorization.
5. No provider has been contacted or granted RUNLU written commercial permission.

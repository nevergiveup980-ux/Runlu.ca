What just happened?

No password was sent. No permanent connection is required. This demo creates a local activation receipt in your browser and verifies that receipt locally when the simulated network is off. Releasing the device removes the local receipt.

This is a safe simulation. It uses a demo key, a virtual device ID, and browser storage only. RUNLU production signing keys, customer data, activation APIs, and private license rules are not included.

Tip: activate, switch the network to OFFLINE, then refresh this page. The demo receipt should remain valid on this browser.

“A license shouldn't need the internet to remember that you own it.”

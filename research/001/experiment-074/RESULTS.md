# E074 — Standardization Target Sensitivity Result

Subgroup rates remain fixed:

EASY: A 90%, B 80%.
HARD: A 30%, B 20%.

The standardized absolute rates change substantially with target mix.

Using A's observed mix (mostly HARD), both standardized rates are relatively low.

Using B's observed mix (mostly EASY), both are relatively high.

Using a 50/50 mix or the declared 30/70 operational example gives intermediate values.

However, the A-B standardized difference remains exactly 10 percentage points under every target in this fixture.

Why?

Within both strata:
A_s - B_s = 0.10.

Therefore for any common target weights summing to one:

sum_s w_s(A_s-B_s) = sum_s w_s(0.10) = 0.10.

## Core result

Target choice can strongly change standardized absolute headlines even when it does not change the comparison direction.

The earlier question "can the headline reverse merely by choosing a target?" receives a negative answer for this particular fixture.

That negative result is structural, not a failure of the audit.

## Boundary

The OPERATIONAL_EXAMPLE target is illustrative only. It is not a measured warehouse population.

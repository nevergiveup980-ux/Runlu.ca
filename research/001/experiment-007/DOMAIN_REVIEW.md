# E007 Domain Review Checklist

Before treating the CHSH bridge as more than an analogy, answer each item with evidence.

- [ ] Can route condition x be defined from information genuinely local to Agent A?
- [ ] Can route condition y be defined from information genuinely local to Agent B?
- [ ] Are x and y sufficiently independent for the intended benchmark?
- [ ] Is there a real operational reason that 00/01/10 require matching actions while 11 requires different actions?
- [ ] Can HOLD/YIELD and COMMIT/GO be defined without ambiguity?
- [ ] Is the payoff safety-relevant rather than merely mathematically convenient?
- [ ] Would delayed or redundant classical communication solve the task more simply?
- [ ] Would a central observer be available in the real deployment?
- [ ] Can the agents pre-share state without violating the comparison?
- [ ] Is there any credible future path to physical quantum resources at both endpoints?

Until this checklist is substantively satisfied, E007 remains **mathematical analogy only**.

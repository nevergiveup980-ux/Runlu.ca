# E102 — Ancestry Depth Sensitivity Result

The same synthetic ancestry graph was audited at four traversal depths.

Depth 0 -> 5 families  
Depth 1 -> 4 families  
Depth 2 -> 2 families  
Depth 3 -> 1 family

For demonstration only, a declared diversity threshold of at least 3 families was applied.

At depth 1 the threshold is met.
At depth 2 it is not met.

Nothing about the underlying graph changed. Only the ancestry boundary changed.

## Core result

Provenance Diversity = f(Ancestry Depth).

A claim of model-family diversity can therefore be depth-sensitive.

The threshold in this fixture is not a scientific universal. It exists only to expose the flip.

## Important limit

Deeper is not automatically better. If META is too generic to transmit the failure mode under study, merging everything at depth 3 can be scientifically misleading.

Thus ancestry depth must be paired with failure-mechanism relevance.

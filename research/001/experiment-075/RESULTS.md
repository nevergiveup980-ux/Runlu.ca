# E075 — Target-Weight Flip Boundary Result

Fixed synthetic subgroup rates:

EASY:
A = 90%, B = 70%, so A-B = +20 percentage points.

HARD:
A = 30%, B = 50%, so A-B = -20 percentage points.

Let w be the target population's EASY fraction.

Then:

D(w) = 0.40w - 0.20.

The exact crossover is:

w* = 0.50.

Therefore:

- w < 0.50 -> A < B;
- w = 0.50 -> tie;
- w > 0.50 -> A > B.

Examples:

w = 0.49 -> A < B.
w = 0.50 -> tie.
w = 0.51 -> A > B.

## Core result

When subgroup effects genuinely differ in direction, there is no population-free overall winner in this fixture.

The standardized headline is a function of both the fixed subgroup performance and the declared target population.

This is not an excuse to choose favorable weights. The target population must be justified independently of the desired conclusion.

This is an exact synthetic construction, not an empirical warehouse comparison.

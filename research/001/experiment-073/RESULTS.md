# E073 — Aggregation Reversal Result

Synthetic fixture:

EASY:
- A = 9/10 = 90%
- B = 80/100 = 80%
- within stratum: A > B

HARD:
- A = 30/100 = 30%
- B = 2/10 = 20%
- within stratum: A > B

Thus A has the higher rate in every declared stratum.

Raw pooled results:

A = 39/110 ≈ 35.45%.

B = 82/110 ≈ 74.55%.

The pooled headline reverses direction:
A < B.

Why?

A's observations are weighted heavily toward HARD cases, while B's are weighted heavily toward EASY cases.

## Core result
The reversal requires no arithmetic error.

Subgroup composition alone can reverse a pooled comparison.

Therefore a pooled difference must not be described as a within-stratum method effect when group exposure differs.

## Boundary
This is a deliberately constructed synthetic Simpson's-paradox fixture. It is not evidence about warehouse methods or policies.

# E099 — Interaction-Model Multiplicity Result

The same synthetic pair AB is evaluated under four pre-admitted interaction models.

M1 SOFTWARE_ONLY -> DEPENDENT  
M2 CALIBRATION_ONLY -> SEPARATE  
M3 SOFTWARE_AND_CALIBRATION -> SEPARATE  
M4 CROSS_LAYER_K9 -> DEPENDENT

M5 LABEL_ONLY is excluded because its admission basis is unresolved.

Across the complete admitted family, the result is:

MODEL_SENSITIVE

If an analyst keeps only M1 and M4, the apparent result becomes STABLE_DEPENDENT.

If the analyst instead keeps only M2 and M3, the apparent result becomes STABLE_SEPARATE.

Both apparent stabilities are artifacts of subset selection.

## Core result

Model multiplicity can become conclusion multiplicity.

A conclusion that is stable only after choosing a favorable subset of admissible models is not family-robust.

No majority vote is used: 3-to-2, 20-to-1, or any other model count is not automatically evidential weight because model families can contain redundant formulations.

## Scope

Synthetic governance fixture only. This experiment demonstrates selection sensitivity; it does not estimate how often model shopping occurs in real research.

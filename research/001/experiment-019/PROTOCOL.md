# Experiment 019 — Reproducibility Gate for Track A

## Purpose
Rebuild the original fallback-correlation lane so that headline results are generated by code, reproducible, and compared against the correct classical controls.

## Scope
E019 does not introduce a new coordination policy. It audits/recomputes E001–E005.

## Required controls
1. Exact enumeration whenever the finite policy/state space permits it.
2. Seeded pseudorandom trials only where enumeration is impractical.
3. Paired scenarios for policies compared on sampled worlds.
4. Matched information and action budgets.
5. Deterministic local policies plus randomized-classical mixtures.
6. Convex-hull/Pareto comparison; no arbitrary weighted winner score.
7. Machine-generated result artifacts; no manually typed headline numbers.

## Gate
A fallback-correlation candidate advances only if it survives all matched classical controls. Otherwise record:
**No correlation-specific advantage demonstrated in this policy class.**

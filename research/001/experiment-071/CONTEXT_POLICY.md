# E071 — Numeric Context Policy

For comparative headline numbers, preserve:
VALUE + UNIT + DENOMINATOR + BASELINE + POPULATION + WINDOW + METRIC + SCOPE.

A shorter display may move context into an immediately adjacent caption/tooltip/footnote only if the association remains unambiguous.

Do not publish a bare percentage whose interpretation changes materially with the omitted denominator, baseline, population, or scope.

## Next drill — E072
Attack denominator substitution.

Two percentages can look comparable while using different denominators, conditioning events, populations, or windows.

Build a comparability gate before allowing side-by-side numeric claims:
SAME_METRIC
COMPATIBLE_DENOMINATOR
COMPATIBLE_POPULATION
COMPATIBLE_WINDOW
COMPATIBLE_SCOPE

# E059 — Model Family Policy

A model family is defined by its core forgetting/causal assumption, not superficial formula naming.

Family assignment must be recorded before using it to change consensus.

Report:
- every admitted model instance;
- its family;
- raw model count;
- family-level count;
- internally split families.

Never clone a model across many parameter values and describe the resulting votes as independent corroboration.

## No automatic equal-family truth
Giving each family one vote is an anti-pseudoreplication diagnostic, not proof that all families deserve equal epistemic weight.

## Next drill — E060
Attack family assignment itself.

A model can plausibly sit between two families, and family boundaries can be manipulated just like model admission.

Build a dependency graph based on shared assumptions instead of forcing hard clusters. Compare:
- raw count;
- hard-family count;
- dependency-aware effective diversity.

Question: can we measure how many genuinely distinct assumptions support a conclusion without pretending independence is binary?

# Experiment 002 — Matched Action Budget

## Purpose
Experiment 001 showed a safety/throughput trade-off. Experiment 002 asks whether correlation itself changes joint outcomes when the ordinary baseline is allowed essentially the same marginal GO budget.

## Comparison
Both policies require positive local evidence. Both pass that evidence through a 70% GO gate.

- Matched-independent: A and B use separate random gates.
- Correlation: A and B use the same pre-shared classical gate.

Thus marginal action frequency is matched in expectation; the difference is whether fallback randomization is independent or correlated.

## Metrics
GO rate, disagreement, unsafe action, successful joint action, and deadlock.

## Claim boundary
This remains a synthetic classical test. A favorable result would show value from shared classical correlation in this modeled coordination problem, not quantum advantage and not yet real-world Warehouse OS performance.

# E024 — Pre-Analysis Guardrails

1. Stopping-margin state was introduced for operational meaning, not to reproduce a Bell payoff.
2. Uniform independent states are only the first exact audit distribution.
3. Tight-priority is conditional on unequal states; equal-state behavior remains visible through conflict/deadlock/progress.
4. Fixed right-of-way is expected to achieve perfect progress but only partial tight-priority satisfaction. That is a legitimate tradeoff, not a defect in the benchmark.
5. Shared classical randomness is evaluated against the convex hull of all deterministic local policy vectors, never only the discrete deterministic frontier.
6. If the classical hull already covers every operationally meaningful target, record another negative result.
7. No quantum/nonclassical calculation is allowed until the native classical frontier is characterized.

# RUNLU KNOWLEDGE — First-batch editorial intake plan

Status: **planning and candidate intake only**. No record below is fact-checked, license-approved, translation-approved or published by virtue of appearing here.

## First pilot: flooring knowledge (5 candidate records)

| Candidate | Scope | Primary source to inspect | Verification question |
| --- | --- | --- | --- |
| Carpet area units (square feet, square yards) | Global (unit definitions) | NIST SI / unit-conversion guidance | Is 1 square yard = 9 square feet, and how should rounding be disclosed? |
| Carpet roll width and cut planning | Product-specific | Manufacturer installation / specification sheet | Which width is actually specified for the exact product and dye lot? |
| Carpet seams and direction | Product-specific / regional | Manufacturer installation instructions and applicable industry standards | Which seam orientation, pile direction and installation constraints apply? |
| Flooring waste estimation | Project-specific | Measured plan plus documented estimating method | Which assumptions and layout decisions drive waste rather than an unsupported universal percentage? |
| Dye lot consistency | Product-specific | Manufacturer labeling and order documentation | Which identifiers and color-matching limits apply to the actual batch? |

These are **research questions, not validated claims**. Do not use an assumed standard or universal waste percentage without verifying the source and context.

## Candidate record acceptance checklist

1. Capture publisher, original URL, publication or effective date, and access date.
2. Distinguish factual claim, interpretation, estimate and product-specific instruction.
3. Check primary evidence and an independent corroborating source where feasible.
4. Record geographic applicability, measurement units and product-specific caveats.
5. Record the source's copyright/license status and link to supporting terms. A link alone does not confer reuse rights.
6. Write original concise English content; translate and separately review Chinese, French and Spanish.
7. Assign stable RK ID through the controlled intake process; no duplicate IDs.
8. Obtain named reviewer sign-off for facts, rights and translations before moving to `approved`.
9. Archive the reviewed version, then include only expressly approved records in the public export.
10. Retain source-check and update dates; recheck when standards, manufacturer instructions or links change.

## Initial batch definition of done

- At least five genuine flooring records with traceable primary sources and explicit scope.
- Independent factual and copyright/license review completed for each record.
- Four-language titles and summaries checked for technical meaning.
- No record displayed publicly until all publication gates pass.
- Search, filters, language switching and mobile experience verified on a preview.
- GitHub Actions green; unrelated site-wide failures documented separately, not silently waived.

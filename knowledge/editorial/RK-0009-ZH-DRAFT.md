# 为什么客户越来越多，自己却越来越累？

星期一早晨，经营一家小型清洁公司的亚历克斯收到一位潜在客户的消息。这正是他过去梦寐以求的长期订单。然而，他并没有感到兴奋，而是望着日程表，琢磨着又该牺牲哪一个晚上的私人时间。

生意扩大了，经营者能够支配的时间却没有增加。

本文为一般教育用途，不构成针对个人的财务、用工或医疗建议。人物、经营案例、计算表和记录模板均为原创虚构示例。

## 1. 需求增加，不等于经营容量增加

每接受一位客户，就意味着作出一份承诺：在约定地点、时间，按照约定标准完成服务。兑现承诺所需的工作，往往在服务开始之前就已经发生，并在服务结束后继续。

经营容量，是指企业在现有资源和约束条件下能够可靠完成的工作量。对于独立经营者，个人时间往往是重要限制；对于有团队的企业，车辆、设备、合格人员和客户场地的开放条件同样可能成为限制。

日程越来越满，说明存在市场需求，却不意味着企业的交付能力有所改善。销售额增长的同时，应对员工临时缺席或者预约延误的能力反而可能下降。

加拿大商业发展银行（BDC）2025年6月的一篇文章援引一项超过600人参与的调查，指出受访经营者平均每周工作49.7小时。这个数字反映的是调查结果，并不是建议的工作时长，也不能代表每一位经营者的实际情况。

## 2. 给每一个工作小时归类

亚历克斯最初只记录现场清洁的时间。然而，一次两小时的服务还需要安排场地进出、开车往返、准备用品，有时还有后续沟通。

试着连续一周，把实际经营时间划分为四个互不重复的类别：

- 服务交付：完成向客户承诺的服务。
- 交通往返：与业务相关的出行及相应等待。
- 协调与管理：排期、采购、开票、沟通及监督。
- 返工补救：修正服务缺陷，或补做此前遗漏的约定任务。

真正因业务产生的临时中断，应在备注中记录，并把相应时间归入合适的类别。例如，在客户现场等待时打了一通业务电话，不应把同一段时间重复计算。开车时不要操作记录表。

客户看不到的工作，也可能十分必要。开票、安全检查和沟通都有其价值。记录时间并不是为了把所有非直接服务时间都视为浪费。

客户付费增加了原约定之外的服务，应记作新增服务交付，而非一概列入返工。

## 3. 找到真正制约经营的瓶颈

假设三位客户都要求在同一个晚上接受服务。亚历克斯拥有足够的设备，却无法同时出现在三个地方。再买一台机器，并不能解决这个冲突。

应该找出反复妨碍企业兑现承诺的资源或决策限制：究竟是经营者的时间、车辆、客户场地的开放条件，还是某项专业技能？

把延误的订单及其原因简单记录下来。如果同一种问题反复出现，先调查原因，再决定是否购买软件或招聘人员。也不要假定所有延误都来自同一个瓶颈。

在原本就有富余能力的环节节省时间，不一定能明显增加整体交付能力；改善真正受限的环节，却可能在不延长经营者工作时间的情况下腾出业务空间。

## 4. 对比两个普通工作周

下面是亚历克斯的简化虚构案例。表中记录的是经营者本人的时间，而非全体员工的工时总和。

| 经营活动 | 增长前（小时） | 增长后（小时） | 增加 |
|---|---:|---:|---:|
| 服务交付 | 24 | 30 | 6 |
| 交通往返 | 6 | 9 | 3 |
| 协调管理 | 5 | 7 | 2 |
| 返工补救 | 3 | 4 | 1 |
| 合计 | 38 | 50 | 12 |

每周增加12小时，相对于原来的38小时，增幅约31.6%。新增时间中只有一半来自直接服务，另外6小时同样需要关注。

亚历克斯自行设定每周40小时的经营时间规划上限。这只是案例中的个人选择，不是用工法规，也不是关于安全工作时长的建议。

目前每周工作50小时，相对于这一上限，存在10小时的容量缺口。

**经营者时间缺口 = 预计经营工时 − 自定经营工时上限。**

结果为正，意味着计划已经超出所选上限；结果为负，意味着账面上还有余量，但不保证某一具体预约能够安排进去，也不保证能够应对突发事件。

## 5. 先改善流程，再考虑扩大投入

亚历克斯查看上一周的预约，发现两个距离较远的客户可以安排在同一天服务，前提是得到客户同意。

统一的到达通知和集中保存的场地进出说明，可能减少反复沟通；简短的完工检查表，也可能减少遗漏任务。

他提出三项改善试验：每周减少3小时交通、2小时管理以及1小时返工。这些都是待验证的假设，而非已经实现的效果。如果全部奏效且没有引发新问题，每周工时将从50小时降至44小时。

好的改善试验必须能够观察结果。比较调整前后的交通耗时、预约遗漏、客户投诉及补救时间。服务标准不能随意降低；涉及预约或者合同条件变更的，应取得相应同意。

对于独立经营者，这些方法可能比招聘更实际。适当缩小服务区域、明确预约时段、减少过多的服务变体，也值得尝试。但调整之前应考虑客户是否方便、收入可能受到的影响，以及已有承诺。

不要为了让记录表上的数字更漂亮，就取消安全程序或必要的休息。

## 6. 分工是责任转移，不是工作消失

假设亚历克斯有一位经过培训且具备空余工作能力的同事，可以每周承担4小时服务。但由此需要增加1小时监督与协调时间。

| 拟议改善措施 | 经营者节省时间（小时） |
|---|---:|
| 优化交通安排 | 3 |
| 简化管理流程 | 2 |
| 减少返工 | 1 |
| 转交服务任务 | 4 |
| 新增监督时间 | -1 |
| 净节省时间 | 9 |

调整后，经营者每周工时为50减9，即41小时。距离40小时的目标仍差1小时，不能宣称已经达到目标。

同事承担的4小时也是真实工作。如果没有其他人员调整和额外培训，案例中的两人合计工时为45小时。初期培训还可能使第一周的工时更长。

分工之前，应明确服务标准、出入权限、所需技能、处理异常情况的授权以及完工检查方法。同时考虑工资或承包费用、相关用工成本、保险与适用义务。

经营者腾出一个小时，并不自动意味着企业多获得一个小时的利润。BDC有关合理分工的指导可供参考；本例的时间核算则为独立创作的虚构规划案例。

## 7. 下一位客户，究竟该不该接？

亚历克斯目前预计每周工作41小时，仍需找到1小时可持续的改善空间，或者重新考虑现有承诺。假如进一步优化路线确实能够节省1小时，工时就会降至40小时，但此时没有任何应变余量。

与其立刻把日程再次填满，不如考虑在40小时上限内预留3小时应变时间，把常规工作目标设为37小时。以此前41小时的计划为基准，距离这个常规目标还有4小时缺口。

**可用规划余量 = 工时上限 − 应变预留时间 − 预计常规经营工时。**

例如，一份新订单每周需要2小时现场服务、半小时交通以及半小时管理，共占用3小时常规经营时间。在当前余量为负的情况下，这份订单无法纳入既定计划。

经营者可以建议客户推迟开始日期，经客户同意调整服务安排，寻找可靠的额外帮助，或拒绝订单。已有承诺必须得到尊重。提高报价可能改善经济效益，却不会自动缩短一项原本需要3小时的工作。

应变时间应根据实际业务波动设定，并非人人都适用3小时。家庭生活、个人事务和休息也应得到明确安排，而不是寄希望于忙完之后自然还有时间。

## 8. 七天经营时间账本

把下面的空白表格复制到笔记本或电子表格中，每天晚上记录实际工时。统一使用十进制小时，例如半小时记为0.5。

| 日期 | 服务 | 交通 | 管理 | 返工 | 合计 | 主要中断或限制 |
|---|---:|---:|---:|---:|---:|---|
| 周一 | | | | | | |
| 周二 | | | | | | |
| 周三 | | | | | | |
| 周四 | | | | | | |
| 周五 | | | | | | |
| 周六 | | | | | | |
| 周日 | | | | | | |
| 全周合计 | | | | | | |

如果当周情况特殊，应加以注明。在作出长期经营决定之前，最好在具有代表性的忙季和淡季分别记录。

每周结束时，问自己六个问题：

- 哪项承诺或资源最经常造成延误？
- 下一周可以试验哪一项流程改善？
- 哪项服务质量或安全指标必须得到保障？
- 改善措施需要增加多少个人工时、团队工时及现金支出？
- 预留可预见的应变时间之后，还剩多少常规经营余量？
- 新订单应该接受、延期、调整服务，还是拒绝？

用实际测量结果更新下一周的计划。如果试验没有成功，就修正原来的假设，而不是悄悄改变成功的标准。

日程排得满满当当，可以是一种成就。而一家既能兑现对客户的承诺，又能让经营者拥有自己生活的企业，则是另一种成就。

**经营的成长，不只在于日程里能够装下多少订单，更在于企业能够为人的生活创造怎样的可能。**

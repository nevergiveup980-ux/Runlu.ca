# 为什么报价看着有利润，订单做完却亏了钱？

**RUNLU KNOWLEDGE™ · RK-0008 · 中文文学化实用改编初稿 v0.1**

**状态：** 内部编辑稿，尚未完成核验，未经批准不得发布。

一家小型清洁公司的老板接到一份新合同。报价发出去，客户同意了，日程排得满满当当，工作也按时做完。可到了月底，老板把工时、耗材、停车费和往返路程算在一起，却发现：原来以为能赚的钱，怎么剩下这么一点？

问题未必只在报价高低，而在于：**当初报价时设想的工作，和后来实际完成的工作，可能已经不是同一回事。**

报价，是对未来成本的预测；项目成本核算，则是用真实记录检验这份预测。

## 一、报价时，我们到底算进去了什么？

假设加拿大有一家虚构的小型清洁公司，承接一处办公室的每周保洁，合同月价为 **1,200 加元**。老板预计每月需要 24 小时人工。

为了便于演示，假设每小时的**综合人工成本**为 25 加元。这只是教学用的假设数字，不代表任何地区的实际工资水平、法定雇主成本或最低工资要求。

| 每月预计项目成本 | 加元 |
|---|---:|
| 人工：24 小时 × $25 | 600 |
| 清洁耗材 | 60 |
| 交通及停车 | 40 |
| 分摊的企业间接费用 | 100 |
| **预计成本合计** | **800** |
| **合同月收入** | **1,200** |
| **扣除上述成本后的预计结余** | **400** |

账面上看，这份报价相当不错。但这里的 400 加元，只是**按上述成本范围计算的项目结余**，并不必然等于企业财务报表中的净利润。计算结果取决于哪些成本被纳入，以及间接费用如何分摊。

更重要的是：这个预计结果有一个前提——实际工时、耗材、交通和工作范围，都与最初设想相差不大。

## 二、工作做起来以后，发生了什么？

假设客户陆续提出，希望公共区域打扫得更细致一些。清洁人员完成任务所需的时间增加，耗材用得更多，交通费用也略有上升，但固定月价没有改变。

实际账目变成了这样：

| 每月实际项目成本 | 加元 |
|---|---:|
| 人工：34 小时 × $25 | 850 |
| 清洁耗材 | 90 |
| 交通及停车 | 60 |
| 分摊的企业间接费用 | 100 |
| **实际成本合计** | **1,100** |
| **合同月收入（不变）** | **1,200** |
| **扣除上述成本后的实际结余** | **100** |

注意，**这个基本情景还没有亏损**。扣除表中列出的成本后，仍然有 100 加元结余。

但原本预计的 400 加元，现在只剩 100 加元，**300 加元的预期结余不见了**。

这 300 加元究竟花在哪里？多出的 10 小时人工增加了 250 加元，耗材增加了 30 加元，交通增加了 20 加元，三项合计正好 300 加元。本例中分摊的间接费用保持不变。

这就是为什么，日程排满了，并不等于每一份合同都达到了原先预计的盈利水平。

## 三、再看一个独立情景：真正发生亏损

现在另设一种**额外的假设情况**：由于一次清洁失误，公司需要返工，新增成本 **150 加元**，而这笔费用不能再向客户收取。

新的总成本是 **1,100 + 150 = 1,250 加元**。合同收入仍为 1,200 加元，因此扣除所列成本后的结果是 **负 50 加元**。

**这才是本文所说的亏损情景。** 不能把前面仍有 100 加元结余的基本情景直接称为亏损。这里的负 50 加元是一个包含假设间接费用分摊的项目层面结果，并非真实企业的会计净利润或税务结果。

设置这个情景，不是说返工必然发生，而是说明：当原有结余已被侵蚀得很薄时，一次额外支出就可能使项目转亏。

## 四、五种容易悄悄吞掉利润的成本

**1. 没有如实记录的人工时间。** 原以为两小时能完成的任务，实际每次都要将近三小时。开门、准备工具、收拾物品、填写记录，这些零散时间一个月累积起来可能不少。与其凭记忆估算，不如记录真正归属于该项目的工时。

**2. 工作范围不断扩大。** 客户要求增加房间、提高频率、提升清洁标准，或者安排合同里原本没有的任务。偶尔提供一点额外服务可以是有意识的客户维护，但应分清：这是一次主动赠送，还是未经重新报价就永久增加了工作量。

**3. 耗材和设备成本。** 清洁剂、消耗品、配件更换、设备磨损和垃圾处理等费用，可能超过最初预计。设备费用尤其需要采用一致的核算方法，避免既直接计入项目成本，又通过间接费用重复计算。

**4. 交通与进场成本。** 距离、停车、进入建筑物的手续、等待时间以及额外往返，都可能让一项看似简单的工作变得昂贵。报价不能只看人在客户场所内实际清洁的分钟数。

**5. 返工。** 补做遗漏的任务、修正错误或重新到场，都会消耗额外人工与材料。最好把返工单独记录，别让它混在正常服务时间里，看不出问题所在。

当然，成本增加不等于企业就有权自动向客户加价。价格能否调整，要看双方约定的工作范围、合同条款以及获得的授权。

## 五、利润率和加价率，别混为一谈

同一份报价，可以算出两个不同的百分比。

按最初预计数字：收入 1,200 加元，列示成本 800 加元，预计结余 400 加元。

**按收入计算的预计项目结余率** = 400 ÷ 1,200 × 100 ≈ **33.3%**。

**按预计成本计算的加价率** = 400 ÷ 800 × 100 = **50%**。

一个以售价为分母，一个以成本为分母，所以不能把 33.3% 和 50% 当作同一个概念。

由于本例的 400 加元已经扣除了假设分摊的间接费用，33.3% 应理解为**按本文列示成本计算的简化项目结余率**，而不能不加说明地称为所有会计口径下通用的毛利率。

基本情景的实际结余为 100 加元，占收入约 **8.3%**；在另外增加 150 加元返工成本的独立情景中，结余变为负 50 加元，占收入约 **−4.2%**。

谈百分比之前，先说清楚分子和分母是什么。

## 六、间接费用怎么分摊，才不会重复计算？

直接成本通常较容易对应到某个项目：现场人工、实际耗材、停车票据或分包费用。间接费用则可能包括行政管理、记账、软件、办公场所等多个项目共同使用的资源。

为了比较不同合同，企业可以按照一种有记录、前后一致的方法，把部分间接费用分配给各项目。上例中的 **100 加元分摊额纯属假设**，不是推荐标准。换一种分摊方法，算出的项目结余可能也不同。

还要记住：分摊到项目上的费用，不一定意味着当月为该项目另外支付了一笔现金。车辆、设备或管理费用也不能既在直接成本里算一次，又在间接费用里再算一次。

项目成本核算和现金流管理也不是一回事。一份合同即使按上述假设仍有结余，如果客户迟迟没有付款，企业照样可能缺现金。这个时间差问题，咱们在 RK-0007 中已经单独讨论过。

## 七、开工之前，先把工作范围写清楚

一份实用的工作范围说明，不必写得复杂，却应该明确：服务地点、频率、房间和区域、具体任务、特殊要求、进入场所的安排、耗材由谁提供，以及约定价格。

对于周期性服务，最好区分**常规工作**和**周期性或额外工作**。例如，每周办公室保洁，不必然包含地毯深度清洗、玻璃清洗或装修后的彻底清理。

当客户提出新要求时，记录改变了什么、预计增加多少时间或成本，以及双方是否同意调整范围或价格。这样做不是为了斤斤计较，而是为了让双方都清楚约定的内容。

具体仍须以真实合同和适用规定为准。本文不是法律意见，也不意味着企业可以单方面修改合同。

## 八、一张可以反复使用的“报价与实际成本核对表”

每项工程或周期性合同，都可以使用下面的栏目。纸笔、电子表格或者简单的软件工具都能胜任。

| 核对项目 | 接单之前 | 工作完成之后 |
|---|---|---|
| 约定价格 | 记录报价及计费周期 | 确认实际可收金额 |
| 工作范围 | 列出区域与任务 | 记录增加或取消的项目 |
| 人工 | 预计工时及综合成本 | 记录实际工时与同口径成本 |
| 耗材 | 预计使用量 | 记录实际消耗 |
| 交通 | 预计次数、距离及停车费 | 记录实际往返与费用 |
| 设备 | 选定直接计费或分摊方法 | 前后一致地应用 |
| 间接费用 | 写明分摊假设 | 使用一致口径核对 |
| 返工 | 考虑风险及预留余地 | 单独记录实际返工 |
| 变更 | 明确额外工作的批准人 | 保存确认记录及调整后的约定 |
| 项目结果 | 收入减去预计纳入成本 | 收入减去同口径实际成本 |

对于持续性合同，最好在前几次服务之后就进行检查，而不是等到年底才发现问题。比较时要采用相同的时间周期和成本分类。

如果实际工时持续超过报价假设，还要进一步判断：这是短期异常、操作效率问题，还是工作范围已经长期改变。

## 九、什么时候应该调整经营方式？

**优化流程。** 如果工作范围没有变化，却因为路线安排、准备工作或排班不合理而浪费时间，就先改进流程。但不能为了节省成本牺牲安全或承诺的服务质量。

**重新讨论工作范围。** 如果客户经常要求合同之外的任务，应把额外工作记录清楚，并提出双方都明白的调整方案，而不是让未经报价的工作悄悄变成默认义务。

**重新审视报价。** 如果连续多次的真实成本都超过原先假设，就需要分析原因、解释情况，并在尊重现有合同的前提下讨论未来价格。

**必要时放弃不合适的订单。** 如果合理成本已无法由报价覆盖，双方也无法调整范围，那么不接这份工作，可能比继续增加营业额更理性。

真正重要的问题，不只是“这份合同拿到了没有”，而是：**“我们是否真正了解，兑现承诺需要付出多少成本？”**

## 十、保护小企业的一项简单习惯

最有用的项目成本管理，不一定需要复杂软件。先建立一个简单循环：

**预计 → 记录 → 比较 → 查找原因 → 调整。**

预计给出起点；实际记录告诉我们哪些假设错了；认真比较，才能把一次不愉快的经营结果变成下一次报价的经验。

日程排满，说明市场有需求；客户签字，说明双方达成约定。但这两件事，都不能单独证明一份订单真正有利润。要判断结果，必须看实际做了什么、付出了多少成本，以及采用了怎样的计算口径。

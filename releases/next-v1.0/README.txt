RUNLU NEXT V1.0 — Customer Edition

START
Open RUNLU_NEXT_V1.0.html in a modern browser. No installation is required.

CORE
The V1.0 planner runs locally in the browser. Core planning, focus sessions, unfinished-item carryover, preference learning, and daily restart do not require a paid AI API.

DATA
Plans, unfinished items, focus history, and learned preferences are stored in the browser's local storage. Clearing browser data can remove that local history.

PRIVACY
Core V1.0 planning does not need to send the brain dump to RUNLU cloud services.

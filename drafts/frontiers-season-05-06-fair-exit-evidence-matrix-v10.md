## Rubric calibration and evidence codes
Six dimensions remain: (D1) discoverability, (D2) billing clarity, (D3) deletion control, (D4) data portability, (D5) retention transparency, (D6) freedom from coercive farewell design.
Each cell must include evidence type: DOC (official documentation), OBS (independent observation), EXP (controlled experiment), POLICY (legal terms), UNKNOWN.
Only when independently validated may a dimension receive a 0–2 usability score. DOC can establish that a path is described; it cannot by itself establish actual task success, time-to-complete, or emotional-pressure absence. No total scores or rankings yet.

## Scenario-based test protocol (future, only with authorization)
Scenario A: user stops conversations but keeps account.
Scenario B: user wants billing stopped without losing data.
Scenario C: user wants a portable copy before deletion.
Scenario D: user wants account deletion and clarity about data retention.
Scenario E: user encounters farewell wording and attempts to disengage.
For each: record platform/device, subscription channel, product version, country, date, path, number of screens, warnings, time to reach confirmation, and any data-loss or payment risk. **Do not perform irreversible deletion or purchase.**

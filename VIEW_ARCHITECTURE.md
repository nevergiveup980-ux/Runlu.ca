# RUNLU VIEW architecture

RUNLU VIEW uses a lightweight landing page plus independent article pages.

- `frontiers.html` is the stable four-language landing page and directory.
- `view-catalog.js` is the small catalog updated when new VIEW pieces are published.
- `view-archive-001-010.html` preserves the founding inline editions 001–010 intact.
- VIEW 011 and later are independent HTML pages.
- New articles should also be added to `sitemap.xml`.

This keeps the main VIEW page small while allowing the library to grow without a practical article-count ceiling.

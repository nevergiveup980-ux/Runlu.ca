Editorial principles

A bridge, not an owner.

Respect the original. Explain accurately. Name the limits. Return readers to the researchers.

编辑原则

做桥梁，不做成果的占有者。

尊重原创，准确解释，说明局限，把读者带回研究者与原始资料。

Principes éditoriaux

Un pont, pas un propriétaire.

Respecter l’original, expliquer avec exactitude, nommer les limites et ramener les lecteurs vers les chercheurs.

Principios editoriales

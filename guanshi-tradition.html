This is GUANSHI's learning and model-dependency sequence, not a claim that each tradition historically descended from the one before it.

《易经》 → 阴阳 → 五行 → 八卦 → 干支 → 八字 → 六爻 / 梅花 → 风水

这是观势的学习与模型依赖顺序，不是硬说每一种传统在历史上都由前一种直接“生出来”。

Yijing → Yin–Yang → Cinq phases → Bagua → Troncs et branches → Bazi → Six lignes / Meihua → Feng shui

Il s’agit d’une séquence d’apprentissage et de dépendance des modèles, non d’une généalogie historique simple.

Yijing → Yin–Yang → Cinco fases → Bagua → Troncos y ramas → Bazi → Seis líneas / Meihua → Feng shui

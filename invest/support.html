Contact support

For technical issues, accessibility requests or questions about RUNLU INVEST, email hello@runlu.ca. Please include the app version, device type and a description of the problem. Never send passwords, brokerage credentials or unredacted investment backups.

Common questions

Does RUNLU INVEST trade securities? No. It is a personal research and record-keeping tool, not a broker or trading service. It does not provide live quotes or personalized investment advice.

Where are my records? The current web app stores records in the browser on your device. The iOS version is in development and stores prototype records locally on the device. Records are not automatically synchronized between devices or between the web and iOS versions.

How do I protect my records? On the web version, use the Backup section to export a JSON backup and keep it in a private, secure location. Web JSON exports are not encrypted. Do not delete existing backups when testing the iOS version. Native backup and migration features are still being validated.

How do I report a bug? Email the steps to reproduce, device and OS version, and screenshots with personal financial details removed.

中文支持

如需技术支持、无障碍使用帮助或报告问题，请发邮件至 hello@runlu.ca，说明设备型号、应用版本和问题现象。请勿发送密码、券商登录信息或未经脱敏的投资备份。

是否提供证券交易？ 不提供。本产品用于个人投资研究和决策记录，不执行交易，不提供实时行情或个性化投资建议。

记录存在哪里？ 当前网页版本将记录保存在设备的浏览器中；正在开发的 iOS 原型将记录保存在本机。不同设备及网页与 iOS 版本之间不会自动同步。

如何备份？ 网页版可在 Backup 页面导出 JSON 文件。导出的 JSON 未加密，请妥善保管。iOS 备份与数据迁移功能尚在验证，请勿删除原有备份。

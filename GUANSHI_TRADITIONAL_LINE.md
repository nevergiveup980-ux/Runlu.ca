## Why this line exists

The traditional line is organized for learning and model dependency:

**《易经》 → 阴阳 → 五行 → 八卦 → 干支 → 八字 → 六爻 / 梅花 → 风水**

This arrow is **not** a claim that each item historically descended from the previous item in a simple chronological chain. The systems developed over long periods, often in parallel, and were repeatedly recombined by later traditions.

GUANSHI therefore keeps two maps at once:

1. **Learning sequence** — a practical order for understanding how concepts are reused by later systems.
2. **Historical source map** — the earliest or most influential texts we can responsibly identify, with uncertainty preserved.

The first deep-dive pass is now complete across all eight nodes.

## T08 · 风水 / Feng Shui — Grammar of Environment

### Core extraction
Feng Shui brings the source line into physical place, but GUANSHI keeps two ledgers separate.

**Measurable environment**
- daylight / solar exposure;
- temperature;
- ventilation and air quality;
- noise;
- access and circulation;
- usable space / crowding;
- safety and accessibility;
- privacy and sightlines;
- terrain, drainage and moisture;
- orientation when it changes measurable sun, wind, heat, noise or view.

**Traditional symbolism**
- qi and wind-water formulations;
- directional correspondences;
- symbolic mountain/water forms;
- bagua / five-phase correspondences;
- compass-school rules;
- auspiciousness and school-specific fate/prosperity claims.

### Source anchors
- `葬书 / Zangshu` transmitted tradition, with attribution/textual-history cautions;
- modern historical studies of Chinese geomancy;
- modern environmental-health and building evidence for the measurable layer.

### GUANSHI rules
- The environment can matter. Why it matters must be demonstrated layer by layer.
- Measure first. Symbolize second. Test added value last.
- Environmental evidence for temperature, noise, air quality or safety does not validate unrelated symbolic rules.

**Deep dive:** `guanshi-fengshui.html` / `GUANSHI_FENGSHUI.md`

# Completed dependency map

The useful conceptual dependencies are:

- **Yijing** — change, position and transformation.
- **Yin–Yang** — relational polarity.
- **Five Phases** — system relations, cycles and feedback prompts.
- **Bagua** — compact state classes and images.
- **Stems/Branches** — time encoding.
- **Bazi** — person + calendrical time.
- **Six Lines / Meihua** — explicit event questions and forecasts.
- **Feng Shui** — environment, siting and spatial symbolism.

This remains a **model-dependency map, not a simple genealogy**.

The completed translation chain is:

**Change → Relation → System → State → Time → Person × Time → Event → Environment**

The line then returns to the central GUANSHI question:

> After facts, context, time, people, events and environment are separated and weighted by evidence, what direction has the strongest real momentum?

That is **势 / Dynamics**.

# Source protocol · V1.1

Every traditional node keeps four records:

1. **Primary text** — what an original or canonical text actually says.
2. **Textual history** — date, authorship, layers, later commentary and uncertainty.
3. **Modern scholarly interpretation** — how historians/scholars describe the system.
4. **Empirical claim audit** — if the node makes a measurable claim, what modern evidence says.

A traditional statement is never upgraded merely because it is old, famous or internally coherent.

A modern scientific finding about one variable is never used to certify an entire traditional system.
